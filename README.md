## 🚀 Getting Started

### Step 1: Install Python
Download Python from [python.org](https://www.python.org/downloads/) — make sure to check **"Add Python to PATH"** during installation.

### Step 2: Verify Installation
Open your terminal/command prompt and run:
```bash
python --version
```
You should see something like: `Python 3.10.x`

### Step 3: Run Your First Lesson
```bash
cd module-01-intro-ai-python/lessons
python 01_what_is_ai.py
```
