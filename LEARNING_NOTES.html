Section 1
What is Artificial Intelligence?

🧠 Definition

Artificial Intelligence (AI) is the simulation of human intelligence by machines — especially computers. It enables machines to:

  • Learn from experience
  • Reason about problems
  • Understand language
  • Perceive images and sounds
  • Make autonomous decisions
💡
Key Insight A calculator is not AI. But a program that learns to recognize cats in photos? That is AI! The difference is learning from data.

📜 Brief History of AI

1950
Alan Turing proposes the "Turing Test" — can a machine fool a human?
1956
The term "Artificial Intelligence" is coined at the Dartmouth Conference.
1997
IBM Deep Blue defeats Chess world champion Garry Kasparov.
2012
Deep learning breakthrough — AlexNet dominates ImageNet competition.
2020
GPT-3 launches — 175 billion parameter language model by OpenAI.
2022
ChatGPT launches and AI goes mainstream — 100M users in 2 months.

AI vs ML vs Deep Learning

The Russian Doll Analogy

Artificial Intelligence
Making machines smart
Machine Learning
Learning from data
Deep Learning
Neural networks
🧩
Key Rule Every Deep Learning system is ML. Every ML system is AI. But NOT every AI system uses ML!

🤖 Artificial Intelligence

What: The broad field of making machines simulate human thinking.

How: Rules, logic, search, data — any approach.

Example: A chess program using search + rules.

📈 Machine Learning

What: AI that learns patterns from data, without explicit rules.

How: Feed data → algorithm finds patterns → makes predictions.

Example: Email spam filter trained on 10,000 emails.

🧠 Deep Learning

What: ML using layers of artificial neurons (neural networks).

How: Data flows through many layers, each learning features.

Example: ChatGPT, DALL-E, Tesla Autopilot.

🔄 Traditional Programming vs Machine Learning

Old Way: Traditional Programming

Data + Rules you write → Answers

You manually write: IF email contains "FREE MONEY" → SPAM

New Way: Machine Learning

Data + Answers → Rules discovered automatically

Show 10,000 labelled emails → AI figures out the rules!

Python Fundamentals
🐍
Why Python for AI? Python is the #1 AI language because of its simple English-like syntax, massive ecosystem (NumPy, Pandas, TensorFlow, PyTorch), and huge community. It's used by Google, Tesla, Netflix, and NASA.

📦 1. Variables

Variables are named containers for storing data. Python has 4 basic data types:

str  "Hello AI" int  42 float  3.14 bool  True / False 
# Creating variables
student_name = "Alice"           # str  → text
age          = 20               # int  → whole number
gpa          = 3.8              # float → decimal
is_enrolled  = True             # bool → yes/no

# f-strings — smart text formatting
print(f"Hello, {student_name}! Age: {age}")
# Output: Hello, Alice! Age: 20
Python

🔁 2. Loops

Loops let you repeat code without writing it multiple times.

# for loop — repeat a known number of times
for i in range(5):
    print(f"Step {i}")
# Output: Step 0, Step 1, Step 2, Step 3, Step 4

# Loop through a list
subjects = ["Math", "AI", "Python"]
for subject in subjects:
    print(subject)

# while loop — repeat while condition is true
count = 0
while count < 3:
    print("Learning AI!")
    count = count + 1
Python

🛠️ 3. Functions

Functions are reusable blocks of code. Write once, use many times! (DRY = Don't Repeat Yourself)

# Define a function
def greet(name):
    message = f"Hello, {name}! Welcome to AI class."
    return message

# Call the function
result = greet("Alice")
print(result)   # Hello, Alice! Welcome to AI class.

# A more complex function
def classify_temperature(temp):
    if temp < 0:   return "Freezing"
    elif temp < 25: return "Comfortable"
    else:           return "Hot"
Python

📋 4. Lists

Lists store multiple items in one variable. Items are ordered, changeable, and indexed from 0.

# Creating a list
ai_tools = ["ChatGPT", "DALL-E", "Gemini", "Copilot"]

# Indexing (starts at 0!)
print(ai_tools[0])   # ChatGPT   (first)
print(ai_tools[-1])  # Copilot   (last)
print(ai_tools[1:3]) # ['DALL-E', 'Gemini'] (slice)

# Common operations
ai_tools.append("Claude")    # Add to end
ai_tools.remove("DALL-E")   # Remove item
print(len(ai_tools))          # Number of items
print(sorted(ai_tools))       # Alphabetical order

# Looping through a list
for tool in ai_tools:
    print(f"Tool: {tool}")
Python

Program 3 — Simple AI Decision Tree

def classify_animal(has_wings, lives_in_water):
    if has_wings and not lives_in_water:
        return "Bird"
    elif lives_in_water and not has_wings:
        return "Fish"
    elif has_wings and lives_in_water:
        return "Duck"
    else:
        return "Land animal"

# This is how early AI worked — decision trees!
print(classify_animal(True,  False))  # Bird
print(classify_animal(False, True))   # Fish

Reference
Glossary
Artificial Intelligence (AI)
Machines simulating human intelligence — learning, reasoning, perceiving.
Machine Learning (ML)
AI that learns patterns from data without being explicitly programmed.
Deep Learning (DL)
ML using deep neural networks with many layers of artificial neurons.
Neural Network
A connected system of nodes inspired by the structure of the human brain.
Training Data
The labelled dataset used to teach a machine learning model.
Model
The result of training — a learned program that can make predictions.
Algorithm
A step-by-step set of instructions used to solve a problem.
Variable
A named container that stores a value in a Python program.
Function
A reusable block of code defined with def that performs a specific task.
Loop
A control structure that repeats a block of code multiple times.
List
An ordered, mutable collection of items stored in a single variable.
Narrow AI
AI designed for one specific task — the only type that exists today.
